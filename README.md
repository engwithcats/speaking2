# Fairytopia Questions ✨

Браузерная игра для подготовки к ЕГЭ по английскому (говорение, Task 2): ученики учатся задавать вопросы к пунктам объявления.

Задание на главной: *You are considering visiting Fairytopia and now you’d like to get more information.*

## Режимы

| Режим | Что делает |
| --- | --- |
| **Flashcards** | 43 карточки: правила, 41 категория шаблонов вопросов (конспект «Говорение 2») и универсальный шаблон *What is the ___ of ___?*. Карточки переворачиваются (нажатие / пробел), листаются кнопками, стрелками или свайпом. В конце — «Начать сначала» или «Выбрать другой режим». |
| **Mix & Match** | Пункт из списка «Уникальные пункты» + перепутанные слова правильного вопроса. Слова перетаскиваются (или нажимаются) в нужном порядке. Раунд: 10, 20 или все вопросы. |
| **Test yourself** | Случайный пункт — ученик задаёт вопрос устно, затем «Показать ответ» и «Далее». |
| **Fight** | Дуэль двух учеников: один генерирует PIN, второй вводит его. Оба получают одинаковые 30 вопросов Mix & Match (одна попытка на вопрос). Побеждает тот, у кого больше правильных ответов, при равенстве — кто быстрее. |

## Как опубликовать на GitHub Pages

1. На GitHub: **Settings → Pages**.
2. **Source: Deploy from a branch**, выберите ветку с игрой и папку **/ (root)**, нажмите **Save**.
3. Через 1–2 минуты игра будет доступна по ссылке вида `https://<имя-пользователя>.github.io/speaking2/`.

Прямые ссылки на режимы: `…/speaking2/#flash`, `#mix`, `#test`, `#fight`.

## Как работает дуэль

GitHub Pages — статический хостинг без сервера, поэтому игроки соединяются напрямую друг с другом через WebRTC ([PeerJS](https://peerjs.com/) и его бесплатный публичный сервер). Регистрации и настроек не нужно.

* Создающий дуэль должен держать страницу с PIN открытой, пока друг не подключится.
* В редких школьных или корпоративных сетях прямое соединение блокируется — тогда поможет мобильный интернет.
* Для проверки на одном компьютере откройте две вкладки с `?local=1` (например, `index.html?local=1#fight`).

## Файлы

* `index.html`, `css/style.css`, `js/app.js` — сама игра.
* `js/templates.js` — шаблоны вопросов по категориям (из документа «ЕГЭ Task 2 — пункты вопросов», раздел «Категории для шаблонов заданий»).
* `js/questions.js` — банк «пункт → правильный вопрос» (369 уникальных пунктов; сгруппированные пункты раскрыты в несколько примеров, всего 436 вопросов). Вопросы можно править прямо в этом файле.
* `assets/` — маскот и картинка Фейритопии.
